## 列出会话

```
GET /v1/sessions
```

列出已认证用户的所有会话。

## 列出活跃会话

```
GET /v2/sessions/active
```

仅列出活跃（未结束）的会话。

## 创建会话

```
POST /v1/sessions
```

**请求体：**

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `tag` | string | 客户端生成的会话标签（用于创建或加载会话） |
| `metadata` | string | 加密的会话元数据 |
| `agentState` | string | 加密的 agent 状态（可选） |
| `dataEncryptionKey` | string | 加密的数据加密密钥（可选） |

## 删除会话

```
DELETE /v1/sessions/:id
```

永久删除会话。

## 发送消息

```
POST /v3/sessions/:id/messages
```

在单次请求中发送一条或多条消息。

**请求体：**

```json
{
  "messages": [
    {
      "content": "encrypted-ciphertext-string...",
      "localId": "local-123",
      "trackCliDelivery": false
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `messages` | array | 1-200 个消息对象 |
| `messages[].content` | string | 加密的消息内容（密文字符串） |
| `messages[].localId` | string | 客户端生成的 ID，用于去重 |
| `messages[].trackCliDelivery` | boolean | 跟踪 CLI 投递状态（可选，默认 `false`） |

**响应：**

```json
{
  "messages": [
    {
      "id": "clx...",
      "seq": 42,
      "localId": "local-123",
      "sentBy": "user",
      "sentByName": "Alice",
      "createdAt": 1774483200000,
      "updatedAt": 1774483200000
    }
  ]
}
```

## 获取消息

```
GET /v3/sessions/:id/messages
```

分页获取消息历史记录。

**查询参数：**

| 参数 | 类型 | 说明 |
|-------|------|-------------|
| `before_seq` | number | 获取此序列号之前的消息 |
| `after_seq` | number | 获取此序列号之后的消息 |
| `limit` | number | 返回消息的最大数量（默认：100，最大：500） |
