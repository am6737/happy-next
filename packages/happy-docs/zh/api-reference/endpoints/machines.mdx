## 创建机器

```
POST /v1/machines
```

注册一台新机器（运行 CLI 的计算机）。

**请求体：**

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `id` | string | 机器 ID（必填） |
| `metadata` | string | 加密的机器元数据（主机名、操作系统等） |
| `daemonState` | string | 加密的守护进程状态（可选） |
| `dataEncryptionKey` | string \| null | 加密的机器密钥（可选） |

该接口是幂等的：如果已存在具有该 `id` 的机器，则原样返回该机器，而不会重新创建。

## 列出机器

```
GET /v1/machines
```

列出已认证用户的所有机器。

## 获取机器

```
GET /v1/machines/:id
```

按 ID 获取单台机器。如果该机器在已认证用户下不存在，则返回 `404`。

<Note>
没有用于更新机器的 REST 接口。`POST /v1/machines` 仅用于注册机器——如果已存在相同 `id` 的机器，则原样返回该机器(请求体会被忽略),因此它永远不会更新已有记录。机器元数据和守护进程状态只能通过 socket 的 `update-machine` 事件更新。
</Note>
