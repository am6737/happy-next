语音功能在 Happy 移动应用的 **设置 > 语音** 中进行配置。

## Happy Voice（默认）

Happy Voice 内置于应用中，开箱即用 — 无需额外设置或注册。只需在任意会话中点击麦克风图标即可开始语音对话。

Happy Voice 使用基于 Volcengine（字节跳动火山引擎）RTC 的语音网关，采用 Volc ASR -> Doubao LLM -> Volcano TTS 管道。默认为所有用户提供托管网关。

### 音色与语速

你可以在 **设置 > 语音** 中个性化 Happy Voice 的发声方式：

- **音色** — 从多个内置音色中选择。点击音色可在选定前试听；在你另行选择之前会使用默认音色。
- **语速** — 一个从慢到快的滑块，默认为正常。调整它可让语音回复变慢或变快。

<Info>
内置音色针对中文和英文进行了调优，因此这两种语言听起来最自然。
</Info>

### 设置同步

你的语音偏好 — 语言、音色、语速、操作确认、欢迎语，以及任何自托管网关设置 — 都存储在端到端加密的用户设置中，并在你的所有设备间自动同步。

### 自托管定制

如果你想完全控制语音管道 — 选择自己的 STT、LLM 和 TTS 模型，或将语音数据保留在自己的基础设施上 — 可以部署自己的 Happy Voice 网关。

要求：
- 一个 Volcengine（字节跳动火山引擎）RTC "AI agent" 应用 — `VOLC_RTC_APP_ID` / `VOLC_RTC_APP_KEY` — 以及用于 RTC OpenAPI 的 IAM 访问密钥（`VOLC_ACCESS_KEY_ID` / `VOLC_SECRET_ACCESS_KEY`）
- Volcano 大模型 TTS 凭证 — `VOLC_TTS_APP_ID` / `VOLC_TTS_TOKEN`
- 一个与你的 Happy 服务器共享的 `VOICE_AUTH_SECRET`，用于签发应用换取网关访问所用的短期 bearer 令牌

网关运行 Volc seed ASR -> Doubao LLM（经 Ark）-> Volcano 大模型 TTS 管道；这些提供商通过网关的环境变量进行配置。

Happy 应用会从你的 Happy 服务器的 `/v1/app-config` 自动发现网关 URL — 应用中无需设置提供商、网关 URL 或公钥。将你的服务器指向已部署的网关，应用即可自动获取。

详见[自托管](/zh/advanced/self-hosting)获取部署说明。
