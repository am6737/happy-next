---
title: "产物"
description: "可在任意设备上创建、编辑和阅读的加密笔记。"
---

产物是保存在 Happy 中的加密个人笔记。每条产物都是一份简单的文档，包含标题和 Markdown 正文。内容经过端到端加密，只有您的设备才能读取。

## 创建笔记

在产物界面点击 **+** 按钮即可新建笔记。填写标题、用 Markdown 撰写正文并保存。标题和正文两个字段中至少有一个填写了内容，笔记才能保存。

## 查看笔记

在列表中打开任意笔记即可阅读。顶部会显示标题和最后更新日期，正文以带格式的 Markdown 渲染展示。

## 编辑与删除

在笔记的详情界面，您可以：

- **编辑** — 修改标题或正文并保存更改。
- **删除** — 永久移除该笔记。

## 加密

每条产物在离开设备前都会使用各自独立的密钥加密，因此服务器永远无法以明文看到您的笔记标题或内容。
