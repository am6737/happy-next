title: "Sessions"
description: "Create, manage, and interact with AI coding sessions."
---

## List sessions

```
GET /v1/sessions
```

List all sessions for the authenticated user.

## List active sessions

```
GET /v2/sessions/active
```

List only active (non-ended) sessions.

## Create session

```
POST /v1/sessions
```

**Request body:**

| Field | Type | Description |
|-------|------|-------------|
| `tag` | string | Client-generated session tag (used to create or load the session) |
| `metadata` | string | Encrypted session metadata |
| `agentState` | string | Encrypted agent state (optional) |
| `dataEncryptionKey` | string | Encrypted data encryption key (optional) |

## Delete session

```
DELETE /v1/sessions/:id
```

Delete a session permanently.

## Send message

```
POST /v3/sessions/:id/messages
```

Send one or more messages in a single request.

**Request body:**

```json
{
  "messages": [
    {
      "content": "encrypted-ciphertext-string...",
      "localId": "local-123",
      "trackCliDelivery": false
    }
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `messages` | array | 1-200 message objects |
| `messages[].content` | string | Encrypted message content (ciphertext string) |
| `messages[].localId` | string | Client-generated ID for deduplication |
| `messages[].trackCliDelivery` | boolean | Track CLI delivery status (optional, default `false`) |

**Response:**

```json
{
  "messages": [
    {
      "id": "clx...",
      "seq": 42,
      "localId": "local-123",
      "sentBy": "user",
      "sentByName": "Alice",
      "createdAt": 1774483200000,
      "updatedAt": 1774483200000
    }
  ]
}
```

## Get messages

```
GET /v3/sessions/:id/messages
```

Fetch message history with pagination.

**Query parameters:**

| Param | Type | Description |
|-------|------|-------------|
| `before_seq` | number | Get messages before this sequence number |
| `after_seq` | number | Get messages after this sequence number |
| `limit` | number | Max messages to return (default: 100, max: 500) |
