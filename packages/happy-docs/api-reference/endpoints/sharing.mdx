---
title: "Sharing"
description: "Share sessions with other users or via public links."
---

## Private Sharing

### List shares

```
GET /v1/sessions/:sessionId/shares
```

List all users a session is shared with (owner only).

### Share with user

```
POST /v1/sessions/:sessionId/shares
```

**Request body:**

| Field | Type | Description |
|-------|------|-------------|
| `userId` | string | Target user ID |
| `accessLevel` | string | `view`, `edit`, or `admin` |
| `encryptedDataKey` | string | Session key encrypted for the recipient |

### Update access level

```
PATCH /v1/sessions/:sessionId/shares/:shareId
```

Change a user's access level.

### Revoke share

```
DELETE /v1/sessions/:sessionId/shares/:shareId
```

Remove a user's access to a shared session.

## Public Sharing

### Create public link

```
POST /v1/sessions/:sessionId/public-share
```

**Request body:**

| Field | Type | Description |
|-------|------|-------------|
| `expiresAt` | number | Optional expiration timestamp (milliseconds since epoch) |
| `maxUses` | number | Optional maximum number of uses (positive integer) |

**Response:**

```json
{
  "publicShare": {
    "id": "...",
    "token": "abc123...",
    "expiresAt": 1710000000000,
    "maxUses": 10,
    "useCount": 0,
    "isConsentRequired": false,
    "createdAt": 1709000000000,
    "updatedAt": 1709000000000
  }
}
```

### Access public session

```
GET /v1/public-share/:token
```

Access a publicly shared session by token.

### Delete public link

```
DELETE /v1/sessions/:sessionId/public-share
```

Delete a public share link, revoking all access.
