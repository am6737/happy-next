# App Review QR Demo

Attach `happy-next-review-demo-qr.png` to the App Review Information for the iOS submission.

QR code content:

```text
happy://review-demo?version=1
```

Expected behavior:

1. Open Happy Next.
2. Open the QR scanner.
3. Grant camera access if requested.
4. Scan the attached QR code from another screen.
5. The app returns to the previous screen and displays a success message confirming that the review demo QR code was scanned.

This QR code is intentionally static, contains no credentials, does not modify an account, and does not expire.
